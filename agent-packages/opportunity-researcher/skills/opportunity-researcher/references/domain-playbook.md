# 机会情报知识包（Opportunity Playbook）

> opportunity-researcher 的自有知识资产（**Asset，不是 agent**）。取材前先读它，用来分辨"信号 vs 噪音"。
> 分 **A 预装**（耐用、公认、开箱即用）+ **B 沉淀**（真实取材长出来）。**信任红线**：品类规律可直接引用；具体竞品事实必须带可核验来源，否则不写、不编。

---

## A. 预装 playbook

### A1. 真信号 vs 噪音的判据（证据级 A：公认）

| 更像真信号 | 更像噪音 |
|---|---|
| 用户**已经在别处花钱/花时间**解决 | 用户"说想要" |
| 有**可观察行为**（重复、迁移、自建 workaround） | 一次性尝鲜、点赞、转发 |
| **多来源、多平台**印证 | 单平台/单篇报道爆火 |
| 痛点具体到"在什么情境卡住" | 泛泛的"要是有 X 就好了" |
| 正在变化的外部条件（why now） | 长期存在、没人真做成 |

### A2. 品类需求规律：AI 陪伴 / K-pop 关系产品（证据级 B：领域共识）

- **意愿极易表达、极难转成付费/留存**：情感类"好想要"信号要打折，优先找已在别处付费/投入时间的行为。
- **社区行为 > 问卷表态**：粉丝在痛楼/物料/二创上的真实投入，比"你要不要 X"的回答可信得多。
- **关系可积累性**是强信号：能沉淀历史、有养成/回访结构的需求，比一次性互动更值得赌。
- **付费敏感区**：情感依赖、未成年人、高额付费——机会与伦理风险并存，标注风险不回避。

### A3. 分阶段找什么（配合 stage-gating）

| 阶段 | 找哪类机会 | 重点 |
|---|---|---|
| ①探索 | 项目级：新方向 | 有没有真实、可及、未被满足的困境 |
| ②验证 | 能证真/证伪核心的信号 | 信号可不可重复、样本偏不偏 |
| ③扩张 | 功能级：强化已验证核心 | 是否契合核心 + 竞品差距 + 不伤现有用户 |
| ④维护 | 退化/流失信号、小改进 | 稳定优先，可回滚 |

## 使用规则（写给 researcher）
1. 取材时用 A1 判信号真假、A2 套品类规律、A3 按阶段决定找项目级还是功能级。
