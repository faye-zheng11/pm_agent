# 评审知识包（Critic Playbook）

> independent-critic 的自有知识资产（**Asset，不是 agent**）。critic 审查前先读它，命中已知坑就直接点名（带出处）。
> 分两层:**A 预装 playbook**（耐用、公认、开箱即用——出厂就带，是卖点）；**B 沉淀账本**（从真实评审长出来，越用越厚——护城河）。
>
> **信任红线**:本包里"通用反模式 / 品类规律"是公认专业知识，可直接引用；"具体竞品做过什么"必须带**可核验来源**，没有来源不写、不编。critic 对本包内容也按 A/B/C 标注可信度。

---

## A. 预装 playbook（出厂即带）

### A1. PM 通用反模式（跨品类，证据级 A：公认）

| 反模式 | 为什么会失败 | 怎么一眼识别 |
|---|---|---|
| **意愿当行为** | "用户说想要" ≠ "用户会用/会留" | 证据是"她说的"而非"她做的" |
| **幸存者偏差** | 只看成功案例，忽略沉默的失败 | "竞品都有/很火"当依据 |
| **虚荣指标** | DAU/下载/曝光涨了，价值没验证 | 用活跃/流量代替留存/付费/价值信号 |
| **无对照的因果** | 把相关当因果，没有基线 | "上线后涨了"却无对照组/基线 |
| **口径漂移** | 分母/窗口/定义没说清 | 指标没有分母、观察窗、事件定义 |
| **目标用户过宽** | "所有人"= 找不到人验证 | 目标用户写不到"能找到具体的人" |
| **方案先行** | 先有功能，再倒推问题 | 从"做个 X 功能"开始，而非从用户困境 |
| **未标风险的关键假设** | 把假设当事实往下游传 | 关键判断没有"这是假设，靠 Y 验证" |

### A2. 品类专属坑：AI 陪伴 / 关系类产品（证据级 B：领域共识，非某竞品事实）

- **新鲜感悬崖**：AI 陪伴类早期留存常靠新鲜感，第 3–7 天断崖。→ 看"新鲜感褪去后还回不回来"的信号，别用首周高活跃自我安慰。
- **意愿—行为鸿沟尤其大**：情感类产品里"好想和 TA 说话"极易表达、极难转成日常行为。→ 对情感意愿证据要求更硬的行为验证。
- **单向 vs 关系**：一次性 chat/尝鲜 ≠ 建立可积累的关系。→ 审"有没有可积累的关系反馈"，而非单次互动量。
- **情感依赖与伦理线**：涉及孤独、情感依赖、未成年人、心理健康、高额付费时，缺安全/伦理边界=阻断级。
- **付费与情感的冲突**：把情感触点直接货币化易反噬。→ 审付费设计是否伤害关系感。

### A3. 分阶段典型死法（配合 stage-gating 使用）

| 阶段 | 最常见的死法 | critic 重点盯 |
|---|---|---|
| ①探索 | 没有 kill 条件就长期烧钱；不可逆大投入 | 有没有"怎么算错、多久看" |
| ②验证 | 把一次幸运/一小撮种子用户当 PMF 就扩张 | 信号可不可重复、样本偏不偏 |
| ③扩张 | 拍脑袋改动已验证核心、无基线、为改而改 | 有没有对照基线、会不会回归 |
| ④维护 | 无谓大改引入回归、破坏稳定 | 改动是否可回滚、是否防退化 |

### A4. 竞品拆解笔记（模板——**由 PM 填，必须带来源**）

> 不预填任何未核实的竞品事实。每条格式如下，`来源` 为空则该条不可用作证据、只能标"待核实"。

```
竞品：
它做了什么：
结果/数据：
失败或成功的机制（为什么）：
对我们的启示：
来源(URL/日期)：
证据级(A一手可核验 / B二手 / C无来源仅传闻)：
```

## 使用规则（写给 critic）

1. 审查前先扫 A1–A3，命中即在 finding 里点名"这是已知坑：X"。
2. 需要具体竞品/行业事实时：先查 A4 有没有带来源的条目 → 没有就走 web_research 检索并附 URL → 都没有则用模型通用知识但**标"通用参考·需核实"**，不得当作已核实证据。
3. 评审后把新坑回写到 B，把 PM 惯性错误回写到 pm-judgment 台账。
